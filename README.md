## 📌 Description
Study Helper is a simple web-based application that allows users to write, save, search, and manage study notes directly in their browser.

The goal of this project is to provide an easy way to organize study materials without needing accounts or external software. All notes are stored locally using the browser’s localStorage, so they remain available even after refreshing the page.

This project was created as a CS50 Final Project.

---

## 🎯 Features
- Add study notes with a title and content  
- View all saved notes  
- Search notes by keywords  
- Delete notes  
- Data persistence using browser localStorage  
- Clean and simple interface  
- Hosted online using GitHub Pages  

---

## 🛠 Technologies Used
- HTML – structure  
- CSS – styling  
- JavaScript – logic and interaction  
- localStorage – client-side data storage  
- GitHub Pages – deployment  

---

## ▶️ How to Use
1. Open the website  
2. Enter a title and your study note  
3. Click "Add note"  
4. Your notes will appear below  
5. Use the search bar to filter notes  
6. Click delete to remove a note  
7. Refreshing the page will not remove saved notes  

---

## 💡 Project Motivation
This project was built to practice front-end web development and to create a useful tool for organizing study materials. It demonstrates how a fully functional application can be created using only client-side technologies.
